# Savvy

Multi-tenant SaaS that runs roofing operations with AI agents. Core CRM first; SupplementIQ (insurance) is a premium add-on.

## Start building (Claude Code)
1. Open this repo in Claude Code.
2. Read `CLAUDE.md` (the standing brief), `DATA-MODEL.md`, and `ROADMAP.md`.
3. Paste the contents of `docs/BUILD-PROMPT-phase0-slice.md` to scaffold Phase 0 + the vertical slice.
4. Approve the plan it returns, then let it build (Phase 0 → vertical slice).

## Docs
- `CLAUDE.md` — architecture, conventions, non-negotiables, definition of done
- `DATA-MODEL.md` — core schema, RLS, enums
- `ROADMAP.md` — phased build plan
- `docs/BUILD-PROMPT-phase0-slice.md` — first Claude Code prompt

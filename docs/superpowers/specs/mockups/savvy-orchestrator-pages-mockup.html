Audit principle
The checker is never the doer. Tier 1: deterministic invariants (SQL against prod state). Tier 2: a second model re-does a random sample of judgment work — re-prices estimates, scores call transcripts. Tier 3: external truth — QuickBooks, Stripe, carrier portals. Disagreement at any tier → exception in Today. Raw run telemetry (the old Command Center) lives one click deeper, per agent.

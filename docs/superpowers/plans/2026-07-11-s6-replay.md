# S6 — Replay (plan)

**Date:** 2026-07-11
**Spec:** `docs/superpowers/specs/2026-07-10-show-the-machine-working-design.md` §5 Slice 6
**Base:** `origin/main` @ 0b18723 (worktree `worktree-replay-s6`). **No migration.**

`/activity?replay=<date>` reads that date's `agent_run` rows (by `startedAt`) and plays them
back on a client scrubber (~`REPLAY_SECONDS`=90 wall-clock, pause/speed), names visible,
**read-only** (still auth-gated). Empty day → "nothing to replay". Reduced-motion → static full
reveal (same facts, no movement). Honesty: nothing shown that didn't happen — every row is a
real historical run.

## Pure logic — `@savvy/core` (unit-tested)
- `tz.ts` (add): `addCalendarDays(civilDate, n): string` and `startOfLocalDayInTimeZone(civilDate,
  tz): Date` (DST-correct, reuses the existing `tzOffsetMs`).
- `replay.ts` (new):
  - `parseReplayDate(raw): string | null` — validates `YYYY-MM-DD` (real calendar date), else null.
  - `replayDayBounds(civilDate, tz): { start: Date; end: Date }` — `[00:00 local, 00:00 next-day
    local)`, DST-correct.
  - `revealedRunCount(startedAtMs: number[], startMs, endMs, progress): number` — how many
    ASC-sorted runs are revealed at wall-clock `progress∈[0,1]`: runs with `startedAt ≤ start +
    progress·(end−start)`. Clamped + monotonic non-decreasing. This is the "by startedAt" honesty
    core.

## Day loader — `@savvy/db`
- `listAgentActivityForDay(tenantId, { start, end }): Promise<AgentActivityRow[]>` — the
  `listAgentActivity` join (customer name via job/lead) with `and(gte(startedAt,start),
  lt(startedAt,end))` and `.orderBy(asc(startedAt), asc(id))`. RLS-scoped (`withTenant`),
  SELECT-only. Export from the barrel; import `asc`.

## UI — `apps/web`
- `command-center-queries.loadReplayDay(date)`: resolve tenant + TZ (`getTenantIdentity`),
  `replayDayBounds`, `listAgentActivityForDay`, map rows → `FeedRow` (`verbFor`). Returns
  `{ rows, date, startMs, endMs }`.
- `activity/page.tsx`: if `sp.replay` present → `parseReplayDate` → render `<ReplayView>` with the
  day's rows; else the existing `<ActivityFeed>`. (No new nav; a `?replay=` link only.)
- `ReplayView` (client): scrubber `<input type=range>`, play/pause, speed (1×/2×/4×); advances
  `progress` by wall-clock over `REPLAY_SECONDS`; reveals `rows.slice(0, revealedRunCount(...))`
  using the existing `ActivityRow`; shows the tenant-local clock at the current position; names
  (`target`) visible. Empty rows → "nothing to replay". **Read-only** (no mutation). Reduced
  motion (`matchMedia('(prefers-reduced-motion: reduce)')`) → start paused at full reveal.

## Tests
- `@savvy/core`: `tz` (day bounds + addCalendarDays incl. DST + month/year wrap), `replay`
